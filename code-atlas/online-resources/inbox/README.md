# Inbox pro ručně získané veřejné nástroje

Zde může uživatel uložit `.js`/`.css` přesně podle `python atlas_resources.py instructions`. Při běžné analýze se tato složka automaticky neprochází a nic se neinstaluje. Po importu jsou prostředky uloženy obsahově adresovaně v `../blobs/` s kontrolou SHA-256.

`online-resources/inbox` není složka analyzovaného projektu. Neukládej sem soukromé zdrojové soubory.
