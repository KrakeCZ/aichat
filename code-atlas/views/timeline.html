Jak číst časovou osu

První zobrazený commit je referenční snímek, ne okamžik vzniku projektu. Git rename se zobrazuje zvlášť od sémantických změn. U přejmenování souboru se tedy mohou v grafu změnit cesty, i když chování programu zůstalo stejné. Pokrytí analyzátoru i kandidátní hrany zůstávají omezením. Žádný soubor ani historie se automaticky neodesílá na server. Pro publikaci na GitHub Pages zkontroluj obsah JSON a commity předem.
