Přibalené analytické technologie

Přibalený offline parser (pouze čtení AST)TypeScript Compiler API

Microsoft a přispěvatelé, verze 5.8.3, Apache License 2.0. Zdroj analyzer/vendor/typescript/typescript.js a celý text licence jsou součástí distribuovaného nástroje. Ke spuštění tohoto adaptéru je potřeba lokální Node.js.

Kompilátorové adaptéry (externí nástroje, nepřibalené)

Použití při instalovaném JDKOpenJDK / javac

OpenJDK a přispěvatelé. Atlas využívá standardní Java Compiler Tree API pro analýzu zdrojových souborů. JDK se přidává uživatelskou instalací; není distribuováno s Atlasem. Analýza nevyžaduje spuštění analyzovaného programu.

Použití při instalovaném ClanguLLVM Clang

LLVM Project a přispěvatelé, licence Apache-2.0 with LLVM Exceptions. Atlas čte Clang AST JSON. Kompilátor není přibalen; výstupy nemusí obsahovat celý build kontext.

Stage 8 — lokální Go a Ruby AST parsery

Volitelný Go toolchain; nepřibalenýGo standard library: go/parser, go/ast + go/types

Projekt Go, původní autoři a přispěvatelé. Atlas využívá AST parser a od Stage 11 také standardní typový kontroler go/types pro vybraná staticky vázaná volání v kompletních lokálních balíčcích. Go toolchain (BSD-3-Clause) instalují uživatelé samostatně. Překlad pomocného programu používá jen standardní knihovnu s vypnutým přístupem k registrům; analyzovaný projekt se nespouští.

Volitelný Ruby interpreter; nepřibalenýRuby Ripper AST parser

Ruby Core Team a přispěvatelé. Atlas používá standardní Ripper S-expressions, nikoli načítání nebo spouštění analyzovaného Ruby projektu. Dynamické volání a require_relative zůstávají v odpovídajících případech kandidátní.

Stage 23 — PHP jazykový tokenizer (externí, nepřibalený)

PHP CLI, pouze lokální validace tokenůPHP tokenizer / The PHP Group

PHP Group, Zend Technologies a přispěvatelé. Stage 23 používá vestavěné token_get_all(TOKEN_PARSE) z volitelného místního PHP CLI pouze ke čtení syntaxe; žádný zdrojový PHP kód projektu se nespouští. PHP interpret není přibalen. Licenční pravidla závisí na jeho verzi: PHP Licensing.

Kotlin AST — volitelně lokálně instalovaný nástroj

Kompilátorový PSI parser při dostupném kotlincJetBrains Kotlin Compiler

JetBrains a přispěvatelé, Apache License 2.0. Parser čte syntax bez spuštění projektu. Kotlin kompilátor není součástí ZIPu, PSI poskytuje syntax. Stage 12 volitelně používá kompilátorový JVM bytecode pro přesně doložitelné statické reference; ostatní volání a JNI runtime zůstávají kandidátní.

Stage 12 — poděkování JVM bytecode technologiím

Použití z lokálně instalovaného Kotlin compileruOW2 ASM

Eugene Kuleshov, Eric Bruneton a přispěvatelé projektu ASM. Používá se shaded ASM z nainstalovaného Kotlin compiler jar pouze ke čtení právě vygenerovaných class souborů. Knihovnu nepřibalujeme samostatně; licence upstream BSD.

Standard JVM ABI, dokumentační zdrojJNI Specification

Specifikace standardních exportních jmen a přetížených parametrických signatur. Shoda jména zůstává kandidátní důkaz, nikoli potvrzení runtime načtení nebo registrace.

Stage 13 — standard JNI registrace

Standard / dokumentace, ne přibalená knihovnaJNI RegisterNatives — Oracle / OpenJDK

Atlas využívá standardní formát JNINativeMethod a porovnává jména, JVM descriptory a skutečné funkční ukazatele. Syntaktická analýza probíhá přes lokálně instalovaný LLVM/Clang, jehož autorům děkujeme výše. Runtime úspěch registrace nelze ze zdrojového kódu potvrdit.

Stage 9 — lokální Swift a Objective-C kompilátorové adaptéry

Volitelný lokální Swift toolchain; nepřibalenýSwift Compiler / Swift project

Swift Project a přispěvatelé. Atlas čte AST výstup nainstalovaného Swift compileru; nejde o náš parser ani o oficiální spolupráci. Zdrojový kód Swift toolchainu je otevřený, podmínky distribuce jeho součástí upravují příslušné upstream licence.

Volitelný lokální Clang; nepřibalenýLLVM / Clang Objective-C frontend

LLVM Project a přispěvatelé. Rozšíření existující integrace Clang AST pro Objective-C a Objective-C++; licence Apache-2.0 with LLVM Exceptions, jak uvádí upstream. Dynamické selector volání se nevydává za jistý cíl.

Výzkumná inspirace — dosud neintegrováno Tree-sitter · SCIP · LSP · Joern · PyDriller · Code Maat · Ghidra · angr · Rizin.

Odlišení součástí

Vnitřní grafy využívají Python ast, Go go/parser, Ruby Ripper a volitelně přibalený TypeScript compiler AST; PowerShell používá AST, pokud je k dispozici prostředí PowerShell, jinak přiznaný lexikální fallback. Tree-sitter, SCIP, LSP ani reverzní analyzátory Ghidra, angr a Rizin ještě integrovány nejsou. Výchozí vykreslovače hlavního grafu používají lokální knihovny ze správy online-resources/; volitelný CDN fallback vyžaduje výslovnou volbu uživatele. PHP tokenizer je samostatný volitelný místní nástroj, nikoli síťové API. Kreditní stránka není náhradou za úplné licenční texty jednotlivých projektů.
